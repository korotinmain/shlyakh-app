# Light and dark themes; the time-of-day sky removed (constellation path, plan 3 of 7) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The app follows the system light or dark theme. Dark is a night sky and light is an ink star chart on a pale background. The seven time-of-day keyframes, `skyAt`, the sun calculator and `skyProvider` are gone. The plan also renames the domain `Route` to `SkyRoute` (a deferred minor from plan 2), before any screen imports it together with Flutter's `Route`.

**Architecture:** One `AppPalette` token set per brightness, as a `ThemeExtension` on `ThemeData`. `MaterialApp` gets `theme` and `darkTheme`, with `themeMode: ThemeMode.system`. Widgets read `context.palette` instead of watching `skyProvider`. Switching the system theme animates through `AppPalette.lerp`. The glass tint and its text colour move into the palette, and `SurfaceTone` is removed.

**Tech Stack:** Flutter `ThemeExtension`, flutter_test (`platformBrightnessTestValue`). No new dependencies.

**Spec:** `docs/superpowers/specs/2026-09-28-constellation-path-design.md` (Decisions → Themes; Components → Presentation → Themes; Success criteria: labels ≥ 11 pt and WCAG AA in both themes). Colours come from the approved concept `full-concept-v4.html` (visual companion).

## Global Constraints

- Theme: `ThemeMode.system`. There is no in-app theme toggle, and no sky that follows the time of day or location.
- Tokens (ARGB). Where a token has three values they are top → middle → bottom for the sky (stops 0, 0.55, 1) and far → near for the hills.

| Token | Dark | Light |
|---|---|---|
| `sky` | `#070B1E` `#161E46` `#2C3670` | `#DCE6F4` `#EEF1F6` `#F6F1E8` |
| `hills` | `#1B2250` `#141A40` `#0E1333` | `#E6ECF2` `#DCE4EC` `#C9D5DF` |
| `accent` | `#F3D9A0` (gold) | `#3D4F9A` (ink blue) |
| `onAccent` | `#1A2440` | `#FFFFFF` |
| `onSky` | `#F4F1EA` | `#1A2440` |
| `onSkyMuted` | `#C8D2F0` | `#3D4F9A` |
| `glass` | `#121836` at 72% (`0xB8121836`) | white at 68% (`0xADFFFFFF`) |
| `onGlass` | `#F4F1EA` | `#1A2440` |
| `grainOpacity` | 0.12 | 0.06 |
| backdrop | nebula: radial `#6E5AA8` at 32% → 0, centre (0.3, 0.3), radius 0.7 | chart grid: 24 pt squares, `#3D4F9A` at 5%, top 2/3 of the screen |

  The concept has only two hill colours, the near ones. The far hill (`#1B2250` dark, `#E6ECF2` light) is one step lighter, so the three code-drawn ridges keep their depth.
- Contrast (WCAG 2), tested:
  - `onSky` against every `sky` stop ≥ 4.5;
  - `onAccent` against `accent` ≥ 4.5;
  - `onGlass` against `glass` composited over each `sky` stop ≥ 4.5;
  - `accent` against `glass` over `sky[0]` ≥ 3 (the active tab and the ring are UI marks, not text).
- Unchanged: glass blur, shadow, track and muted opacities (`GlassStyle`); typography, spacing, radii, motion; member colours.
- Status bar: light icons in the dark theme, dark icons in the light theme.
- Nothing under the tab bar, and labels ≥ 11 pt: the existing Today tab-bar tests keep passing in both themes.
- Tests run with `TZ=Europe/Kyiv`; Pigeon before build_runner.
- `lib/main_preview.dart` is local only and never committed. It is moved out for the coverage check, and its `PREVIEW_HOUR` goes away with `skyAt`: adapt it locally to force a brightness, then move it back.
- Branch `feat/themes` from `main` after PR #25 is merged.
